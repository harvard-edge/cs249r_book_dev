Glossary

This glossary defines key terms used throughout Agentic Machine Learning Systems. Terms are organized alphabetically.

A

Actuation Reversibility Boundary
The architectural threshold separating invertible, volatile internal context operations (such as internal scratchpad modifications or chain-of-thought token generation) from non-invertible, external environment side effects (such as issuing POSIX filesystem mutations, dispatching database transactions, or provisioning remote cloud resources). Crossing this boundary requires persistent state logging, capability verification, or distributed Saga coordination to ensure system recoverability.
Asynchronous Interrupt Vector
A prioritized runtime signaling mechanism that preempts the stochastic processor’s autoregressive execution loop to deliver out-of-band operational events. Interrupts handle human-in-the-loop (HITL) steering, external API cancellations, execution timeouts, and safety monitor trips without corrupting or dropping the in-flight trajectory state.
Autoregressive Covariate Shift
The distribution drift that occurs when an autonomous agent is deployed in closed-loop execution, where its own sampled actions and the resulting environmental observations form the conditioning prefix for future generation steps. While supervised fine-tuning trains models under the teacher-forcing invariant (conditioning exclusively on ground-truth demonstration tokens), closed-loop autoregression causes execution trajectories to rapidly drift away from the training distribution, leading to compounding error decay (\(P_{\text{success}} \le p^N\)).

B

Best-of-N (BoN) Sampling
An inference-time test-time search strategy where \(N\) independent candidate trajectories or reasoning paths are sampled autoregressively in parallel from a stochastic policy \(\pi_\theta\). An external verifier, Outcome Reward Model (ORM), or Process Reward Model (PRM) scores each completed candidate rollout, and the runtime commits only the highest-ranking candidate to external execution.
Blackboard Architecture
A distributed multi-agent coordination topology where heterogeneous, specialized agents communicate asynchronously by reading from and writing to a centralized, structured, and access-controlled shared state graph. The blackboard decouples agent lifetimes, prevents \(O(N^2)\) point-to-point communication overhead, and maintains an immutable audit trail of collaborative problem-solving steps.

C

Capability Lease
A cryptographically signed, scope-restricted, and time-bounded authorization credential issued by an agent runtime kernel. Leases grant an autonomous agent temporary permissions to execute specific tools, modify bounded filesystem paths, or access restricted network endpoints. The kernel automatically revokes or expires leases upon timeout, policy violation, or detection of untrusted context taint, enforcing strict least privilege.
Checkpointing (Trajectory State Checkpointing)
The deterministic serialization and persistence of an agent’s volatile execution state—encompassing active Key-Value (KV) cache tensors, context buffer tokens, working memory variables, pending tool identifiers, and environment mount descriptors—to durable, non-volatile secondary storage. Checkpointing enables low-latency crash hydration, counterfactual backtracking, and asynchronous state suspension without re-executing non-idempotent tool side effects.
Compensating Action (\(A^{-1}\))
A deterministic, pre-compiled reversal operation paired with an external environment actuation within a distributed Saga workflow. When an agent experiences downstream trajectory failure, semantic divergence, or runtime cancellation, the runtime executes compensating actions in reverse order to return the external environment to a consistent, safe baseline.
Context Compaction (Scratchpad Consolidation)
A context-management algorithm that selectively condenses long multi-turn trajectory histories by summarizing completed intermediate steps, consolidating tool stdout observations, and pruning transient reasoning tokens. Context compaction bounds the active Working Set Size (WSS), preventing attention degradation, quadratic prefill latency spikes, and context window exhaustion.
Context Thrashing
An attention memory pathology occurring when the active Working Set Size (WSS) of an agent trajectory exceeds the physical context window or Key-Value (KV) cache allocation. The runtime is forced to continually evict and recompute historical tokens, causing acute latency spikes, attention dispersion, and loss of critical operational constraints.
Cost-per-Verified-Goal (CPVG)
The foundational economic metric of agentic machine learning systems, defined as the total financial and computational cost (encompassing input tokens, output tokens, tool executions, verification passes, and failed rollout retries) divided by the number of independently verified, successfully completed tasks. CPVG replaces raw token pricing as the primary benchmark for deployment economics.

D

DAgger (Dataset Aggregation)
An iterative imitation learning algorithm engineered to eliminate autoregressive covariate shift in multi-step agent policies. DAgger executes the current student policy in the target environment to generate operational rollouts, queries an expert teacher or verified solver to provide corrective actions for the visited states, and aggregates these state-action pairs into the training corpus for subsequent model fine-tuning iterations.
Demonstrator Competence Boundary
The fundamental capability ceiling imposed by supervised fine-tuning (SFT) and behavioral cloning, where the learned policy’s performance is strictly bounded by the empirical distribution and problem-solving quality of human demonstrators (\(D_{\text{KL}}(\pi_{\text{expert}} \,\|\, \pi_\theta) \to 0\)). Surpassing this boundary requires closed-loop reinforcement learning with environmental verification oracles (RLVR).
Distributed Trajectory Tracing
An observability and telemetry framework that instruments multi-step, multi-agent workflows as directed acyclic graphs (DAGs) of causal execution spans. Each trace captures token prefill/decode latencies, tool parameters and return codes, sandbox resource utilization, verification scores, and parent-child agent delegation events, providing root-cause attribution for semantic failures.
Dual-Memory Hierarchy (L1/L2/L3)
A tiered storage architecture for autonomous agents that partitions memory across physical latency and persistence boundaries: L1 Working Memory (volatile, high-bandwidth accelerator KV-cache storing active context tokens), L2 Cached Memory (paged and radix-indexed prefix KV-cache blocks shared in GPU HBM or host RAM), and L3 Episodic Memory (non-volatile, persistent vector and relational stores indexed via semantic embeddings).

F

Fail-Plausible Fault Model
A systems fault model characterizing stochastic foundation models, wherein the processor does not exhibit fail-stop crashes (such as segfaults or panics), but instead generates syntactically flawless, logically coherent, and epistemically confident outputs that are semantically incorrect, hallucinated, or environmentally destructive (Byzantine semantic faults).

G

Grammar-Guided Decoding (Constrained Sampling)
An inference-time token filtering technique that masks vocabulary logits at each autoregressive decode step using a finite-state machine (FSM) or context-free grammar (CFG) parser. Grammar-guided decoding enforces that emitted tool invocations, arguments, and data structures strictly adhere to pre-defined JSON, XML, or SQL schemas, completely eliminating syntax errors before environment dispatch.
Group Relative Policy Optimization (GRPO)
A memory-efficient reinforcement learning algorithm for LLM reasoning and agent rollouts. GRPO samples a group of candidate outputs for each prompt and estimates policy gradient advantages relative to the group’s empirical reward mean and standard deviation, completely eliminating the auxiliary critic (value) neural network and halving training GPU memory requirements.

H

H·S·A Triad (Horizon, State, Authority)
The core systems taxonomy governing agentic architecture: Horizon defines the temporal and token step budget over which an agent plans and acts; State designates the mutability, persistence, and consistency of the agent’s internal and environmental memory; and Authority specifies the blast radius, capability leases, and execution privileges granted to the agent runtime.
Head-of-Line (HoL) Blocking under Pareto Service Times
A severe cluster queueing pathology arising when multi-step agent trajectories—which exhibit heavy-tailed Pareto service distributions with near-infinite variance—are scheduled through standard First-In-First-Out (FIFO) queues. Long-running, multi-hour trajectories monopolize GPU memory and compute slots, causing severe backpressure that delays quick, short-lived tasks.

I

Information Flow Control (IFC) Lattice
A formal security model that attaches dynamic security labels (such as Trusted vs. Untrusted) to all prompts, tool returns, and ingested external documents. The agent kernel evaluates label propagation across string concatenations and context assemblies using a join semi-lattice (\(\tau(C_t) = \bigsqcup_i \tau(x_i)\)), automatically revoking privileged tool capabilities the moment untrusted external data enters the context.
Invariant Closure Principle
An operational safety principle requiring that any environment mutation executed by an autonomous agent must leave the system in a state where all registered safety, consistency, and structural invariants are satisfied. If an actuation violates an invariant, the runtime must prevent state commit and trigger compensating rollbacks or fail-safe containment.

M

MicroVM Sandboxing
A hardware-assisted virtualization isolation mechanism (utilizing lightweight hypervisors such as Firecracker or Cloud Hypervisor over KVM) that encapsulates untrusted agent code execution inside stripped-down virtual machines. MicroVMs provide strict kernel boundary separation, sub-50-millisecond boot times, and ephemeral Copy-on-Write (CoW) filesystem overlays that ensure complete state hermeticity.
Model Context Protocol (MCP)
An open, standardized communication protocol that unifies how autonomous agents discover, inspect, and invoke external tools, databases, and contextual resources across process boundaries. MCP decouples model-specific client implementations from tool provider servers via structured JSON-RPC messaging.
Multi-Head Latent Attention (MLA)
An attention architecture that projects Key and Value activations into a compact, low-rank latent vector prior to caching. MLA substantially compresses the physical Key-Value (KV) cache memory footprint per token on accelerator high-bandwidth memory (HBM) while preserving the expressive representation power of standard multi-head attention.

O

Outcome Reward Model (ORM)
A learned verifier or evaluation oracle that scores only the terminal state or final answer of an agent trajectory, assigning a scalar reward \(R(\tau) \in \mathbb{R}\) based on goal completion without evaluating or attributing credit to intermediate reasoning and tool-calling steps.

P

PagedAttention
An attention algorithm and memory management architecture that partitions Transformer Key-Value (KV) caches into fixed-size virtual blocks allocated on demand across non-contiguous physical accelerator memory pages. Inspired by classical virtual memory paging, PagedAttention eliminates internal and external memory fragmentation, enabling dynamic memory sharing across parallel agent rollouts.
Prefix Caching / RadixAttention
A runtime memory optimization that retains and reuses precomputed KV-cache states for shared token prefixes across distinct queries or sequential multi-turn trajectory turns. Managed through a radix trie, RadixAttention enables dynamic prefix matching, token-level block eviction, and branch sharing, substantially reducing prefill compute FLOPs and Time-To-First-Token (TTFT).
Process Reward Model (PRM)
A step-level verifier that evaluates and scores each intermediate reasoning token chunk or action step within an agent’s execution trajectory (\(r_t = R(s_t, a_t)\)). PRMs provide dense credit assignment, enabling early pruning of erroneous search branches during test-time deliberation.

R

Rejection Sampling
A test-time selection and synthetic dataset filtering technique where multiple candidate trajectories generated by a stochastic model are executed against deterministic verification oracles (such as unit test suites, static analyzers, or formal checkers). Only trajectories that achieve verified correctness are retained for deployment execution or training flywheel ingestion.
Reinforcement Learning with Verifiable Rewards (RLVR)
A post-training reinforcement learning paradigm where policy optimization is driven exclusively by automated, deterministic verification oracles—such as compilers, test execution harnesses, or formal proof checkers—rather than subjective human preferences or learned reward models. RLVR eliminates reward hacking and enables self-improving reasoning over extended trajectory rollouts.
Reward Hacking (Goodhart’s Law)
A reinforcement learning pathology where an agent policy discovers exploitative behavioral strategies that maximize the nominal reward signal without fulfilling the actual task objective. Examples include altering unit test assertions, bypassing validation scripts, or generating degenerate outputs that exploit blind spots in reward models.

S

Semantic Livelock
An active failure mode where an autonomous agent (or an ensemble of collaborating agents) continuously generates coherent thoughts, issues valid tool calls, and mutates environment state without making measurable forward progress toward the user’s objective. Unlike classical deadlocks where execution halts, semantic livelock consumes compute tokens, financial budget, and execution time in infinite circular loops.

T

Test-Time Compute Scaling
The architectural principle of spending additional floating-point operations (FLOPs) at inference time—through extended reasoning scratchpads, candidate rollout branching, verifier scoring, or iterative error correction—to improve problem-solving accuracy on complex tasks without increasing model parameter counts.
Time-To-First-Token (TTFT)
The elapsed wall-clock latency from the moment an agent runtime dispatches a context payload to the inference engine until the accelerator yields the initial generated token. In multi-turn agentic workflows, TTFT is dominated by the prefill phase over accumulating trajectory history and dictates the responsiveness of interactive agent loops.
Trajectory Goodput
The ratio of computational resources, tokens, or trajectories that contribute directly to verified, successful task completions relative to the total resources expended across all rollouts, speculative branches, and failed attempts. Trajectory Goodput serves as the macro-level efficiency metric for agent serving clusters, contrasting with raw hardware token throughput.
Trajectory Replay Invariant
A systems correctness guarantee requiring that deterministic re-execution of logged actions and cached tool observations from a Write-Ahead Log (WAL) reproduces the exact internal agent state without re-dispatching irreversible or non-idempotent side effects to the external environment.

V

Verification Tax
The aggregate computational, financial, and latency overhead incurred by executing secondary verification mechanisms—including Process Reward Models, unit test execution sandboxes, secondary critic LLMs, and formal verification solvers—required to validate stochastic model actions before committing external environment side effects.

W

Working Set Size (WSS)
The minimal collection of context tokens, active state variables, environment observations, and tool schema definitions that an autonomous agent must maintain within its active attention window at step \(t\) to accurately compute the next optimal action without suffering attention dispersion or memory degradation.
Write-Ahead Log (WAL)
An append-only, durable transaction log wherein an agent runtime records each planned action, tool parameter payload, and environment state transition prior to executing the physical actuation. The WAL enforces the Replay Invariant, ensuring that following a node failure or preemption, the trajectory can be hydrated deterministically without duplicating non-idempotent tool side effects.
\(W \oplus X\) Invariant Violation (Write XOR Execute)
The architectural security flaw inherent to autoregressive foundation models, arising because the model ingests executable system instructions and untrusted external data into the identical unified token sequence without hardware-enforced memory protection boundaries. This failure of instruction-data separation makes unconstrained agents fundamentally vulnerable to indirect prompt injection attacks.
